# A bookstack-viewer by AI and ME

Bookstack viewer was created to fetch data from multiple bookstack instances and publish the data in a
controlled way where users must login via their email address. When entering the email address the
user will receive an access token to access the website. Alle user actions are logged.

Because the data is stored in a seperate database the users are not able to modify anything. Images
still link to the origional bookstack environment.


## AI

As an experiment this code was completely generated by promting AI. From a programmers view the code
is messy en unstructured but is does work. It's not effortless to generate code via AI and it's 
certainly not maintainable. It's just a big ball of mud https://en.wikipedia.org/wiki/Anti-pattern

We will continue to investigate AI for code development, but for know we know it is really important
to have humans validate, rewrite, organize and test it.
